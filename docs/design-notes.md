# 「打擾記錄器」視覺設計說明

## 設計方向

以低干擾的石墨深色介面承載資訊，只讓「+1 被打擾」以冷靜青綠成為單一、寬大且不用精準瞄準的操作焦點。

## 色票

下表對比值依 WCAG 的 sRGB 相對亮度公式計算；文字色以實際使用背景為比較基準。邊框是非文字分隔線，仍維持對相鄰底色約 `3:1` 的辨識度。

| 語意名稱 | HEX | 用途 | 對比值 |
|---|---:|---|---:|
| Window Background | `#12171C` | 視窗主背景 | 搭配 Primary `16.46:1` |
| Surface | `#1A2229` | 卡片、次要按鈕、標題列 | 搭配 Primary `14.70:1` |
| Surface Hover | `#222D36` | 滑入與選取底色 | 搭配 Primary `12.82:1` |
| Border | `#5A6F7C` | 外框、卡片與控制項邊界 | 對 Surface `3.07:1` |
| Text Primary | `#F2F5F7` | 大數字、標題、主要正文 | 對 Window `16.46:1`；對 Surface `14.70:1` |
| Text Secondary | `#BCC6CD` | 次要正文、記錄內容 | 對 Surface `9.27:1` |
| Text Muted | `#94A2AC` | 輔助說明、時間與熱鍵提示 | 對 Surface `6.15:1`；對 Hover `5.36:1` |
| Accent | `#4FC3B6` | 主按鈕、選取 Chip、焦點邊界 | 搭配 Accent Foreground `8.72:1` |
| Accent Hover | `#62D0C4` | 主操作滑入狀態 | 搭配 Accent Foreground `10.07:1` |
| Accent Pressed | `#36A99E` | 主操作按下狀態 | 搭配 Accent Foreground `6.51:1` |
| Accent Foreground | `#071513` | 強調色底上的文字與圖示 | 對 Accent `8.72:1` |
| Danger | `#FF7B79` | 錯誤、刪除或無法記錄提示 | 對 Surface `6.41:1` |
| Warning | `#F3C969` | 去重、熱鍵衝突等警示 | 對 Surface `10.25:1` |

正文最低實際組合為 Text Muted 對 Surface Hover 的 `5.36:1`，高於 WCAG AA 正文門檻 `4.5:1`；大字與主要按鈕也高於大字門檻 `3:1`。

## 字級

預設字型為 `Segoe UI Variable, Microsoft JhengHei UI, Segoe UI`，讓 Windows 介面感與繁體中文 fallback 保持一致。

| 名稱 | 大小 | 用途 |
|---|---:|---|
| Display | `52 DIP` | 今日次數大字 |
| Title | `18 DIP` | 視窗標題、主按鈕文字 |
| Body | `14 DIP` | 最近記錄、次要按鈕 |
| Caption | `12 DIP` | Chip、時間、次要資訊 |
| Micro | `11 DIP` | 狀態列與熱鍵提示 |

## 應用程式圖示概念

圖示採「對話泡泡＋加號」：粗線對話泡泡代表外來打擾，加號代表立刻記一筆。輪廓不依賴細節或文字，縮至 `16 × 16` 系統匣尺寸時仍能辨識；`256 × 256` 原圖四周保留安全距離。

- ViewBox：`0 0 256 256`
- 建議背景色：`#12171C`
- 建議前景色：`#4FC3B6`
- 填色規則：`EvenOdd`
- 可直接指定給 WPF `Path.Data` 的幾何路徑：

```text
F0 M 40,36 H 216 V 180 H 136 L 72,220 V 180 H 40 Z M 64,60 H 192 V 156 H 128 L 96,176 V 156 H 64 Z M 116,76 H 140 V 100 H 164 V 124 H 140 V 148 H 116 V 124 H 92 V 100 H 116 Z
```

使用時讓 `Path` 採前景色填滿，外層圖示畫布採背景色；路徑本身已包含泡泡鏤空與中央粗加號。

## 主畫面版面草圖

寬度固定 `340 DIP`，高度 `540 DIP`。元素內距由主題的 Small／Medium／Large spacing token 統一控制。

> 原始草圖高度為 `460 DIP`，實作後實測發現記錄清單只放得下約 2.5 筆就會冒出捲軸，
> 因此加高到 `540 DIP`，讓 5 筆記錄剛好完整顯示。以下為實作後的實際配置。

```text
┌──────────────────────────────────────┐  340 × 540
│ 打擾記錄器        [置頂][統計][設定][×]│  標題列 44
├──────────────────────────────────────┤
│               12 次                  │  今日次數 98
│              今日被打擾               │
├──────────────────────────────────────┤
│                                      │
│            ＋1 被打擾                │  主按鈕 98
│                                      │
├──────────────────────────────────────┤
│ [同事] [主管] [電話] [會議] [其他]   │  標籤列 48
├──────────────────────────────────────┤
│ 最近記錄                             │
│  14:32:05                    同事     │
│  13:48:17                    電話     │
│  11:26:40                    主管     │  清單卡片 194
│  10:15:02                    會議     │  （最多 5 筆）
│  09:41:33                    其他     │
├──────────────────────────────────────┤
│ [撤銷最後一筆]           Ctrl+Alt+D   │  狀態列 58
└──────────────────────────────────────┘
```

主按鈕使用完整寬度的大面積點擊區，視線仍停留在工作內容時也容易命中；介面不配置循環動畫，只用即時的 hover／pressed 色彩切換回應操作。

## 標籤（chip）的狀態表達

| 狀態 | 表現 |
|---|---|
| 未選取 | 深色底、細邊框 |
| 已選取 | 強調色實心填滿、深色文字 |
| 鍵盤焦點 | 內部一圈**虛線**（未選取時白色、已選取時深色），外框與底色都不變 |

鍵盤焦點刻意不用「實心亮色外框」：那和「已選取」的實心填色太像，
使用者會把只是取得焦點的標籤誤認為已選取，進而以為「點不掉」。

## 破壞性動作的處理

刪除記錄無法復原，視覺上分兩階，不讓使用者一步就踩到：

| 階段 | 樣式 | 表現 |
|---|---|---|
| 第一步「刪除這筆」 | `Style.Button.Danger.Subtle` | 透明底、一般邊框、危險色文字。放在左下角，遠離右下角的「取消／儲存」，降低誤點 |
| 第二步「確定刪除」 | `Style.Button.Danger` | 危險色實心填滿、深色文字，旁邊附「刪除後無法復原」 |

危險色的 hover／pressed 兩階（`#FF9694` / `#E56260`）定義在 `Themes/Controls.xaml`，
是從 `Brush.Danger` (`#FF7B79`) 手調出來的；Design.xaml 只定義了基準色。

按熱鍵記錄時另外會在螢幕右下角顯示一個約 2.5 秒的獨立提示視窗（同一套色票、強調色外框），
不使用 Windows 系統匣氣泡，因為氣泡會被「專注輔助」直接吃掉。

## 補充控制項樣式

`Design.xaml` 只涵蓋主畫面需要的控制項。對話框另外需要的 TextBox、CheckBox、
對話框視窗樣式與統計長條，補在 `src/StopAnnoyingMe.App/Themes/Controls.xaml`，
顏色與圓角一律引用本文件定義的 token，不另外定義新顏色。
